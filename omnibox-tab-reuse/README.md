# 已有标签定位 · Chrome 扩展

v1.1.0 · Manifest V3，Chrome 116+，无需构建、账号或服务器。

## 开关与提示

- 新图标为「双标签＋定位箭头」；开启时为绿色，关闭时为灰色并显示 `OFF`。
- 点击工具栏中的扩展图标，打开弹窗，操作「自动定位」开关。默认开启，设置保存在本机，重启浏览器后仍生效。
- 关闭时不切换或关闭标签，也不发送定位提示；重新开启只处理后续导航，不清理关闭期间已打开的重复标签。
- 每次非地址栏导航成功复用已有标签后，显示静音系统通知「已定位到已有标签」，说明重复标签是否被关闭。
- 同时显示工具栏箭头角标，并在弹窗保留本次浏览器会话的最近一次定位记录；打开弹窗时清除箭头角标。
- 系统通知可能受 macOS/Windows 通知设置或勿扰模式影响；通知被屏蔽时仍可查看弹窗记录。
- 弹窗记录只存时间、目标标签 ID、是否关闭新重复标签，不保存网页标题、网址或正文。

## 从旧版更新

将新版文件解压到原来的扩展目录，在 `chrome://extensions` 中点击该扩展的「重新加载」；如 Chrome 因新增通知权限暂停扩展，请查看并接受其权限提示。
也可以加载新版文件夹，但要先停用旧版，避免两份扩展同时处理导航。

## 安装

1. 如果下载了 ZIP，先解压。
2. 在 Chrome 打开 `chrome://extensions`。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `omnibox-tab-reuse` 文件夹。
5. 安装完成后对新发生的导航生效，不扫描并关闭安装前已存在的重复标签。

## 行为

- 顶层导航的 `transitionQualifiers` 包含 `from_address_bar`：直接放行，允许用户从地址栏主动打开重复页面。
- 其他 HTTP/HTTPS 顶层导航：查找当前 Chrome 配置中的同网址标签。优先当前窗口，然后按扩展观察到的创建顺序、窗口 ID 和标签顺序选择。
- 命中后激活目标标签并聚焦其窗口；目标窗口最小化时恢复窗口。
- 只有扩展观察到的新建标签，其首次 HTTP/HTTPS 导航发生重复时，才会自动关闭该新标签。地址栏首次导航也会消耗这一资格。
- 已有标签内的跳转遇到重复时，仅定位目标，保留来源标签及其历史。固定标签、刷新、前进/后退不会导致来源标签被自动关闭。
- 未找到重复标签则不做操作。
- 完整 URL 匹配：浏览器 URL 标准化后比较，保留查询参数及 `#fragment`；不合并不同协议、不同参数、不同 hash、不同路径尾斜杠。

## 范围和限制

- “不来自地址栏”也包括书签、页面链接、脚本跳转、刷新和恢复等，不等于仅来自外部应用。这是按指定的 `from_address_bar` 规则判断。
- `onCommitted` 在导航提交后提供来源信息，因此本扩展不能阻止请求发出，也不能保证完全没有页面闪现或业务副作用。不要将它当作网络拦截器。
- 本版处理 `webNavigation.onCommitted` 顶层文档导航；不处理 iframe、SPA 的 `pushState/replaceState` 或仅 hash 变化。
- 后续重定向以其事件自身的 qualifiers 判断，不能保证跨多个文档的整条脚本重定向链均被视作地址栏发起。
- 当前配置中的普通窗口之间生效；不跨 Chrome 配置，不启用无痕窗口。
- 工作线程休眠后的状态通过 `storage.session` 保留；浏览器重启、扩展重载/更新会重置会话状态。无法确认是新建标签时只聚焦，不关闭。
- 若用户在异步处理期间切换了来源页面，或目标页面关闭/跳转，扩展会尽量放弃关闭操作。Chrome API 不提供跨标签原子事务，仍存在极短的竞争窗口。

## 权限与数据

- `tabs`：读取打开的标签网址，激活或关闭本次新建的重复标签。
- `webNavigation`：获取导航提交事件和来源限定符。
- `storage`：保存本次浏览器会话中的标签创建顺序及首次导航标记。
- `storage.local`：保存开关状态；`storage.session`：保存最近一次定位记录。
- `notifications`：在成功切换到已有标签时显示静音系统通知。
- 不注入网页、不读取网页正文，不上传网址或浏览历史，不使用外部依赖。

## 手动验收

| 操作 | 预期 |
|---|---|
| 已有 A，从新标签地址栏输入 A 并回车 | 两个标签都保留，不切换 |
| 已有 A，从其他 APP 打开 A 到新标签 | 定位已有 A，关闭新建重复标签；实际以 Chrome 提供的来源标记为准 |
| 已有 A，从网页链接在新标签打开 A | 定位已有 A，关闭新建重复标签 |
| 已有 A，在已有 B 内点击链接进入 A | 定位已有 A，B 的来源标签保留 |
| 已有 A，在另一个窗口新建重复 A | 聚焦已有 A 所在窗口 |
| 新标签打开当前未打开的 B | 正常保留 B |
| A 与 A?x=1 或 A#section | 当作不同网址 |
| 短时间多次打开同一网址 | 复用较早标签，避免两个新标签互相关闭 |
| 目标标签关闭、导航变化或激活失败 | 保留来源标签 |
| 点击插件图标关闭自动定位，再从外部打开重复网址 | 不切换、不关闭、不提示 |
| 重启浏览器后打开插件弹窗 | 开关保留上次状态 |
| 成功定位已有标签 | 系统通知、箭头角标和最近一次定位记录出现 |
| 系统通知被屏蔽 | 定位仍完成，弹窗内有最近记录 |
